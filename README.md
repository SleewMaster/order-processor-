# order-processor

Учебный Python-проект для практических работ по Git и GitHub.

Программа проверяет корректность заказа и рассчитывает общую стоимость товаров. В модуле используются функции `calculate_total`, `validate_order` и `process_order`.

## Запуск

```bash
python order_processor.py
```

Ожидаемый результат: `Стоимость заказа: 3100 руб.`

## Работа с GitHub

В рамках РПМ ПР6 репозиторий опубликован на GitHub, изменение документации сделано в ветке `docs-update` через Pull Request.

**Примечание:** проект и история его разработки восстановлены для выполнения учебной работы. Это не оригинальная история ранее утраченной локальной папки.
